# Terreno Matinhos — dossiê técnico

Terreno maior em Troto / Igreja, freguesia de Almancil, concelho de Loulé.

**Objeto exclusivo:** artigo urbano **14883 — 3 285 m²**.
**Construção existente identificada:** 253 m² (armazéns / atividade industrial).
**Parcela excluída:** artigo urbano **14868 — 1 327 m²**.

O levantamento original indica 4 612 m² antes da separação dos artigos (3 285 + 1 327).

- `planta_terreno_maior_3285m2.svg`: planta vetorial esquemática do artigo 14883.

## Advertências
**A planta não é levantamento topográfico válido para obra**, foi interpretada a partir de uma fotografia de um levantamento em papel. Para construir são necessárias coordenadas topográficas originais e confirmação municipal.

O ofício da CML de 25/08/2022 era uma resposta a um **direito à informação**, não uma licença ou PIP aprovado. As normas de solo urbanizável podem estar suspensas desde 31/12/2024 (artigo 199.º RJIGT alterado pelo DL 117/2024). Confirmar exceções/condicionantes e a legalidade da construção de 253 m².
